# 架构与扩展方式

## 先区分五层

| 层 | 职责 | 改它能解决什么 |
| --- | --- | --- |
| 模型 | 理解自然语言，选择工具和参数，阅读回执后继续 | 意图和条件组合，不直接执行 Java/浏览器代码 |
| 业务 Skill | 告诉模型何时使用工具、如何理解业务字段和失败结果 | 调用策略、缺项处理、解释口径 |
| 工具协议 | 可调用的名字、参数 Schema、返回结构 | 模型能表达哪些动作 |
| 执行器/适配器 | 校验、HTTP 请求、DOM 操作、等待和回读 | 动作是否真正完成，以及可执行边界 |
| 原业务系统 | 权限、经济条款校验、保存、审批、数据一致性 | 业务真实性及最终状态 |

本仓库的 Skill 面向开发者；项目内 `src/main/resources/skills/return-swap-booking/SKILL.md` 面向运行中的业务助手。不要直接替换二者。

用户问“这是 Skill 限制还是代码写死”时，沿着实际失败链定位：模型没选择工具看 Skill/工具说明；工具参数被拒绝看 Schema/归一化；工具已调用但执行被拦看执行器；接口失败看权限和业务响应。不要仅修改提示词就声称代码限制已解除。

## Java 编译后如何选择工具

运行时将已实现工具的描述与 JSON Schema 提供给模型。模型返回工具名和结构化参数，Java 调度器找到对应实现执行，再把结果交还模型。模型没有绕过编译器，也没有自动生成一个可以调用任何 Java 类的方法。

项目中有两条路径：

- **业务 HTTP 路径：** `search_operations` 查 OpenAPI 目录，`describe_operation` / `describe_schema` 读取接口细节，`execute_operation` 通过通用客户端执行已允许的操作。接口出现在文档里，不等于已授权执行。
- **页面路径：** `operate_page` 接受有限动作和页面字段；浏览器端独立适配器执行。不是任意点击/脚本工具。

API 的请求方法、参数位置和 Schema 可以数据化，减少逐个写转发代码。但权限、分页差异、特殊编码、经济条款和有副作用的行为仍需明确适配。Swagger 不包含完整页面交互、组件生命周期或业务授权。

## 页面命令如何到达用户浏览器

1. 悬浮助手将用户消息与当前页面线索发送给独立 Agent 服务。
2. 模型选择 `operate_page`；服务端校验动作、字段和当前任务，生成带 ID、标签页归属和期限的命令。
3. 助手页面轮询任务，经受限制的 `postMessage` 交给宿主挂件。
4. 挂件核对来源、登录身份、标签页、期限和重复命令，再调用页面适配器。
5. 适配器打开原生入口、操作控件、等待联动、核对实际结果；回执经认证接口返回服务端。
6. 模型根据回执回答、询问缺项或选择下一步。不能用自己的意图覆盖回执中的失败事实。

悬浮挂件挂在业务应用根节点之外，随主工作台存在，因此 SPA 切换业务页面时可以保留。

命令去重、相同回执重复上报可接受，与“任意业务操作都可重试”不同。超时或刷新后先核对现场，不自动重放未确认命令。当前实现采用等待浏览器回执的任务执行方式；大并发下需评估异步恢复和持久化调度，不把现有线程等待当作无限可扩展。

## 当前用户身份

复用用户当前工作台登录身份：页面登录适配器 → 同域助手的认证请求 → Agent 校验当前会话 → 业务服务继续按同一身份执行权限检查。

- 模型只得到工具名、业务参数和必要结果；不能指定凭据、主机或请求头。
- 凭据不进入模型上下文、任务持久化、Git 或日志；线程切换时显式传递经过校验的执行身份。
- 任务归属和标签页归属分别校验。浏览器 ID 不能代替用户认证。
- 登录切换、退出、过期时停止旧身份的新动作；不退回公共账号。
- 页面线索仅用于理解现场，不是权限证明。

## 哪些变更需要开发

| 需求 | 通常需要的工作 |
| --- | --- |
| “存续”改成“非存续”，或组合已有日期字段 | 使用现有参数和枚举，不增加整套流程 |
| 新增筛选字段 | 核对业务语义，补页面映射、Schema、控件适配和回执核验 |
| 新增同类 HTTP 查询 | 接入接口目录、执行许可、请求/响应差异；能否纯配置取决于现有客户端 |
| 新页面、新向导、复杂产品 | 增加专用动作或适配器，验证生命周期 |
| 模型漏填已知字段或误报结果 | 核对 Skill、工具描述和回执消费；必要时修正代码 |
| 原系统升级控件或路由 | 按新构建版本重新取证和回归 |

Agent 的价值是让用户用意图驱动多步任务，并根据实际结果调整后续动作。可靠执行依赖已接入能力；不承诺免维护或自动理解任意系统。
